# 2026-09-26

## TodoDays 桌面应用从零搭建（Electron + Vue3 + TS + SQLite）

- 完整实现本地桌面日程与 Todo 应用：约 40 个源文件，主进程/预加载/渲染进程三端
- 技术要点：
  - SQLite 用 Electron 内置 `node:sqlite`（DatabaseSync），零原生编译依赖；Electron 37.10.3 + Node 22.16 内核
  - 重复规则展开逻辑放 `src/shared/repeat.ts`，主进程提醒扫描与渲染层日历共用
  - 重复日程数据模型：单条基准记录 + `exception_dates`（删除实例）+ `completed_dates`（按日完成）+ `repeat_group_id`
  - IPC 全部类型化：`TodoDaysApi` 接口 + `IpcChannel` 常量，preload contextBridge
  - 提醒：20s 轮询 + `reminder_log` 表防重复 + Notification + WebAudio 合成提示音
  - 备份用 `VACUUM INTO` 生成一致性快照；恢复前自动留安全副本并 relaunch
- 踩坑记录（重要）：
  1. **npm 首次安装 EBUSY**：esbuild postinstall spawnSync node.exe 报 EBUSY，重跑 `npm install` 即续装成功
  2. **npm 可选依赖缺失**（经典 bug）：`@rollup/rollup-win32-x64-msvc` 和 `@esbuild/win32-x64` 未装上导致 vite/esbuild 无法运行，显式补装解决
  3. **ELECTRON_RUN_AS_NODE=1 被 WorkBuddy 环境注入**：子进程 Electron 以纯 Node 模式启动，`electron.app` undefined。启动前必须 `unset ELECTRON_RUN_AS_NODE`
  4. **WorkBuddy 沙箱内 GPU 进程崩溃**（exit_code=-1073741819）：`app.disableHardwareAcceleration()` 不够，`--disable-gpu` 也不够，必须命令行加 `--in-process-gpu --no-sandbox` 才能跑起来。应用代码里已默认 disableHardwareAcceleration + disable-gpu（`TODO_DAYS_ENABLE_GPU=1` 恢复）
  5. PowerShell Add-Type 截屏被安全策略拦截，无法用此法截 Electron 窗口
- 验证结果：typecheck（tsc + vue-tsc）零错误；electron-vite build 成功；Electron 冒烟运行 34s+ 零错误；数据库 5 表 3 索引自动创建成功
- 运行方式：`npm run dev` 或 `npm run build && npm start`；数据在 `%APPDATA%/todo-days/todo-days.db`

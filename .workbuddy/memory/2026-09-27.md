# 2026-09-27

## TodoDays 打包为 Windows exe

- electron-builder 26.15.3 打包成功，产物在 `dist/`：
  - `TodoDays-Setup-1.0.0.exe`（89MB，NSIS 安装版：可选安装目录、桌面快捷方式）
  - `TodoDays-Portable-1.0.0.exe`（88MB，便携版：双击即用免安装）
  - `win-unpacked/TodoDays.exe`（解包目录版）
- 关键配置与经验：
  1. **dependencies 全部移到 devDependencies**：代码已被 vite 全量 bundle，运行时不依赖 node_modules，这样 electron-builder 不把 vue/pinia 等打进 asar，体积更小
  2. `npm run dist` = `electron-vite build && electron-builder --win --x64`
  3. 镜像变量：`ELECTRON_MIRROR` + `ELECTRON_BUILDER_BINARIES_MIRROR`（npmmirror），打包全程约 2 分钟
  4. 应用图标：ImageGen 生成 → 有"AI生成"水印 → 用 Electron 离屏 Canvas 脚本（`build/fix-icon.js`）做垂直镜像补丁覆盖水印（确定性、零积分）；electron-builder 从 `build/icon.png`（1024x1024）自动转 ico
  5. 打包日志里 "signing with signtool.exe" 是 electron-builder 内置的 asar integrity 处理，非真实代码签名；未签名 exe 首次运行会有 SmartScreen 提示，属正常
- 冒烟验证：`TodoDays-Portable-1.0.0.exe --in-process-gpu --no-sandbox` 在 WorkBuddy 沙箱内成功拉起主进程+渲染进程；普通桌面环境双击即可运行
- 备注：ImageGen 生成/修图共消耗 2 次积分调用；应用默认软件渲染（GPU 兼容），`TODO_DAYS_ENABLE_GPU=1` 可恢复硬件加速
